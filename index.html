把散在五个窗口里的日常，收进一个

每一块都按「真的在管服务器」的标准做：断线要说明原因，命令要能审计，大表要能翻。

SSH 终端

常驻保活不踢线（长任务挂机不被杀）；顶部状态条实时显示 CPU / 内存 / 负载 / 全部真实分区，一次连接循环采样，不会被安全设备当成扫描。

AI 终端 / 数据库助手

原生工具调用驱动，替你跑命令、写 SQL、排障。逐条确认或自动模式由你选择：破坏性操作永远拦下来问你，子代理没有审批权。

批量运维

广播命令到几十台机器、批量传公钥、跨机传输文件、批量上传 —— 并发可控、逐台汇报，失败机器单独点名。

数据库工作台

MySQL / PostgreSQL / Oracle / SQL Server / 达梦 / 人大金仓 / ClickHouse / SQLite / Redis。百万行大表键集分页，编辑、导出、AI 写 SQL 一条龙。

Docker 管理

容器、镜像、日志、终端，文件管理器直接浏览容器内目录（tar 流解析），Compose 可视化操作，走 SSH 隧道管远程宿主机。

告警中心

CPU / 内存 / 磁盘 / 大文件阈值扫描，只读体检脚本不出网、不留痕；命中即提醒，附带 AI 分析与处置建议。

安全基线检查

25+ 项只读基线扫描（口令策略、SUID、计划任务、SSH 配置…），累积台账按机器归档，可导出 PDF / Word 报告。

文件传输

SFTP 双栏管理器：拖拽上传、后台上传队列不挡手、断线重连说明原因；传输进度在托盘常驻。

效率细节

命令收藏一键发送、全局快捷键、多标签分屏、代码高亮编辑器、五个主题。省下来的都是敲命令的时间。

AI 能替你执行，但签字权在你

这不是「把 shell 交给大模型」的玩具，权限模型按生产服务器的标准设计。

逐条审批门

确认模式下每个变更性调用都要你点头；自动模式放行普通操作，破坏性与高危泄露仍然拦下询问。后台任务与主任务同一口径，没有旁路。

只读白名单

机器人与外部 MCP 的「只读命令」按命令 + 参数逐条校验：断网卡、改时钟、删日志、读进程环境变量这类写用法全部拒绝。

本机优先

资产凭据加密存储（AES-256，密钥文件 0600），对话与配置留在本机；不带遥测，不要求注册。

回归防线

AI 内核 340+ 项断言回归：审批门、守卫、哨兵协议、命令判定绕过面逐条钉住——每个修过的洞都有用例看着，不会修好又漏。

功能即插件，宿主不认名字

安全基线、批量运维、端口速查、服务器状态条……都是内置插件。禁用即消失，宿主代码里不留一行分支。

Page

整页插件：导航轨一个图标，打开覆盖主内容区（安全基线、批量运维）。

terminalHeader

终端顶部插槽：常驻窄条 UI（服务器状态条），不占导航图标。

aiContext

AI 上下文：把插件数据作为对话背景注入，自带开关与选择栏。

setup

启动钩子：挂后台订阅，禁用再启用必须幂等。

主进程侧同样按插件组织（electron/plugins/builtin/*），能力由宿主注入 —— 与渲染层同一份契约文档见仓库 PLUGINS.md。
